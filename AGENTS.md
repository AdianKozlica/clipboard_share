# Tech stack:

- Flask
- Tailwind CSS
- Jinja
- SQLAlchemy (with PostegreSQL)
- Python 3.11
- Gunicorn
- Docker
- Docker compose

# Notes:
- Use type hinting in Python
- Keep everything rendered on the server side
- Use pyenv to create .venv/ directory 
- Create the Dockerfile that will be then used in docker-compose.yml to deploy the app
- Store client side code (.js, or .css) in seperate directories assets/css or assets/js respectively
